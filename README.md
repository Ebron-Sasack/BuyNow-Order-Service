# BuyNow Order Service

## Overview

The Order Service processes customer orders, manages order history, and tracks order status throughout the order lifecycle.

## Features

- Create Order
- Order History
- Order Status
- Checkout
- Cart Integration
- Payment Integration

## Tech Stack

- Java 21
- Spring Boot
- OpenFeign
- Spring Data JPA

## APIs

- Create Order
- Get Orders
- Update Order Status
